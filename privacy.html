Privacy policy: MoSaber Comments

Last updated: November 5, 2026

What the app is

MoSaber Comments is a private tool used only by Mohamed Saber, owner of the YouTube channel @mosaberai, to reply to comments on his own videos.

Data it uses

With the owner's permission (YouTube Data API, scope youtube.force-ssl) the app reads public comments on the owner's own videos (comment text, author display name, time) and the titles and descriptions of those videos, and posts replies to those comments as the channel.

How the data is handled

  • The data is processed on the owner's own computer only, to write and post replies.
  • Comment text is sent to an AI writing service (Anthropic's Claude API) only to draft the reply.
  • Nothing is sold, shared for advertising, or given to any other party.
  • Small local logs (which comments were answered) are kept on the owner's computer to avoid replying twice.
  • The access token is stored only on the owner's computer and can be revoked at any time at myaccount.google.com/permissions.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
